# Settings cleanup removal candidates

Status: **prioritized review list only**. P1 rows come before P2 rows. This file records feature-level review candidates found during A1–A3. It does not remove controls, settings, backend fields, actions, or features. “Review” means the owner should decide whether to keep the current surface, group it, move it to Config, or schedule a migration. No row is a Kill decision from the current evidence.

The visibility editor may retain a local removal proposal and a reason for a known entry. That proposal is metadata only. It does not change `settings.json`, Rust defaults, module availability, runtime gates, or feature behavior.

The current B1 baseline is 204 non-dialog controls, 166 managed ownership units (24 Basic and 142 Expert), plus 39 explicit global/navigation exclusions. The 142 Expert units exceed the provisional 60-unit review signal by deliberate choice; no feature is removed to meet a count. Controls, actions, status, logical units, and persisted keys remain separate review dimensions.

## Ordinary controls explicitly protected from pruning

These are important supported controls or actions, not feature-pruning targets: mic capture/device/mode, PTT hotkey, input language, active Whisper model, AI/rule switches, prompt presets and custom prompt text, history aliases, copy/export/archive/delete with confirmation, model download/remove with confirmation, module consent, route save/test, and runtime recovery actions. Their proposed Basic or Expert surface may change; their supported behavior remains in scope.

## Review outcomes and evidence rules

- **Keep** means preserve the setting or action and place it at the proposed Basic/Expert surface.
- **Review** means the owner must decide grouping, copy, or a migration before any removal.
- **Config/Pending** means the value or lane can remain supported without being an active Basic/Expert control until its ownership is clear.
- **Kill** requires demonstrated obsolescence, an explicit owner decision, migration/round-trip fixtures, and a rollback story. No current row meets that bar.
- Candidate reasons may be stored by the local visibility profile for later review. They are bounded to 500 characters by the current profile helper and are not written to `settings.json`.
